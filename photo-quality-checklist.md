# Photo Quality Checklist

## Checklist: Photo Quality Review

### Resolution & Technical Quality
- [ ] **300 DPI minimum** - Verify all listing photos are at least 300 DPI for print quality
  - Check photo dimensions: at least 2000x2000 pixels for best results
  - Test print: preview at 100% zoom to check sharpness
- [ ] **No blurry images** - Remove or replace any blurry/shaky photos
- [ ] **No watermarks** - Ensure no text, logos, or watermarks overlap the product
- [ ] **Proper lighting** - Check for even, natural lighting (no harsh shadows)
- [ ] **No glare** - Reduce reflections on glossy surfaces

### Consistency & Branding
- [ ] **Consistent background** - Use a consistent background color (white, beige, or neutral) across all listings
- [ ] **Consistent angles** - Show the product from the same angles on every listing
- [ ] **Consistent branding** - Add your shop name/cross consistently (bottom corner or subtle watermark)
- [ ] **Consistent file format** - Use PNG or JPEG (no GIF or BMP)
- [ ] **Uniform file size** - Keep file sizes consistent (200-500 KB per photo)

### Lifestyle & Context
- [ ] **Lifestyle shots** - Include at least 1 photo showing the product in a room setting
- [ ] **Scale reference** - Show the product next to a common object (ruler, coin, or furniture) for size reference
- [ ] **Different angles** - Show front, back, side, and top views
- [ ] **Detail shot** - Include a close-up of key features or patterns
- [ ] **Color accuracy** - Verify colors look true-to-life (check on multiple screens)

### Listing-Specific Photos
- [ ] **Cover photo** - Ensure the main cover photo is the most attractive and shows the product clearly
- [ ] **Thumbnail view** - Check that the product is visible in thumbnail size (small preview on search results)
- [ ] **Multiple photos** - Add at least 3-5 photos per listing (more for complex items)
- [ ] **No irrelevant images** - Remove stock photos that don't show the actual product

### Photo Upload Tips
- [ ] **Compress images** - Use a free tool (TinyPNG, Squoosh) to compress without losing quality
- [ ] **File naming** - Name files descriptively (e.g., "boho-wall-art-z-letter-front.png")
- [ ] **Alt text** - Add descriptive alt text for accessibility and SEO
- [ ] **Test on mobile** - Preview listings on mobile device to ensure photos load quickly

## Quick Reference: Photo Requirements

| Requirement | Specification |
|-------------|---------------|
| Minimum DPI | 300 DPI |
| Minimum dimensions | 2000x2000 pixels |
| File format | PNG or JPEG |
| File size | 200-500 KB |
| Background | Consistent neutral color |
| Cover photo | Clear, attractive, shows product well |
| Lifestyle shots | At least 1 room setting photo |
| Angles | Front, back, side, top |
